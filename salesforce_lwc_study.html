Bike Selector の全体像

自転車を選ぶと詳細が変わる仕組みを、画面・コンポーネント・コードの順に見ていきます。

画面イメージ 一覧で自転車を選び、右側に選択した1台の詳細を表示する構成です。

ユーザーに見える画面の概念図

Select a Bike

自転車一覧 · list / tile

DYNAMO X1 →

選択した1台 · detail

選択中
DYNAMO X1

※ 提供された data.js の1件を使った構成イメージです。提供コードに detail.html がないため、詳細欄の実際の表示内容は示していません。

コンポーネントの親子関係

selector 全体をまとめる親
list自転車を並べる
tile × 複数1台ずつ表示
detail選択された1台を探す
data.js → list / detail：bikeslist → tile：product={bike}selector → detail：product-id={selectedProductId}

クリックから詳細表示まで 青は子から親へのイベント、緑は親から子へのプロパティです。

選択した自転車の Id が、名前を変えながら各コンポーネントを通ります。

1tile をクリック

onclick={tileClick} で処理を始める。

2tile → list

tileclick を発行。detail に自転車の Id を入れる。

3list → selector

evt.detail を受け取り、productselected で同じ Id を通知。

4selector が Id を保存

selectedProductId = evt.detail に更新。

5selector → detail

product-id={selectedProductId} で Id を渡す。

6detail が1台を探す

setter で bikes.find(...) を実行し、見つけた自転車を product に保存。

● イベント：子 → 親● プロパティ：親 → 子● コンポーネント内の処理
Id の経路：tile の detail → list の evt.detail → selector の selectedProductId → detail の productId。
detail.js は該当する自転車を product に保存します。

各表の理解度ボタンは「未確認 → 確認中 → 説明できる」で切り替わり、このブラウザに保存されます。

data — 一覧と詳細に使うデータ

list.js と detail.js は c/data から bikes 配列を読み込みます。

提供されたコード：画像URLの https://... は元の記載どおりの省略表記です。画像を実際に表示するには完全なURLが必要です。
data.js
export const bikes = [
    {
        apiName: "Product__c",
        fields: {
            Id: {
                value: "a0256000001F1arAAC"
            },
            Name: {
                value: "DYNAMO X1"
            },
            Category__c: {
                value: "Mountain"
            },
            MSRP__c: {
                displayValue: "$7,800",
                value: 7800
            },
            Material__c: {
                value: "Carbon"
            },
            Picture_URL__c: {
                value: "https://.../dynamox1.jpg"
            }
        }
    }
];
何をしている？理解度コードと詳しい説明
配列として公開する
data.js
export const bikes = [...]

list.js と detail.js は import { bikes } from 'c/data' で読み込みます。現在の提供コードには自転車が1件入っています。

レコードの種類を示す
data.js
apiName: "Product__c"

このデータが Product__c のレコードを表すことを示します。

自転車を一意に識別する
data.js
Id.value

tile は Id をイベントで送り、detail は同じ Id を使って bikes.find(...) で1件を探します。

名前と画像を一覧に表示する
data.js
Name.value / Picture_URL__c.value

tile.html は Name を文字として、Picture_URL__c を画像の src として使います。

カテゴリと素材を持つ
data.js
Category__c.value / Material__c.value

この例では Mountain と Carbon です。提供された tile.html では表示せず、詳細画面などで利用できる値です。

価格の値と表示文字列を分ける
data.js
MSRP__c.value / MSRP__c.displayValue

value は数値の 7800、displayValue は表示用の $7,800 です。提供された tile.html では表示していません。

list — 一覧を作る

data.js の bikes を繰り返して、各自転車を tile に渡します。

list.html
<template>
    <div class="container">
        <template for:each={bikes} for:item="bike">
            <c-tile
                key={bike.fields.Id.value}
                product={bike}
                ontileclick={handleTileClick}>
            </c-tile>
        </template>
    </div>
</template>
何をしている？理解度コードと詳しい説明
データを一覧用のプロパティに保存
list.js
bikes = bikes;

右側の bikes は import した配列、左側は List コンポーネントのプロパティです。HTML から {bikes} で参照できます。

自転車の数だけ繰り返す
list.html
for:each={bikes} for:item="bike"

bikes 配列の各要素を bike という名前で取り出し、c-tile を1個ずつ作ります。

繰り返し要素を一意に識別する
list.html
key={bike.fields.Id.value}

LWC が一覧の追加・変更時にどの要素がどれかを判別するためのキーです。各 bike の Id を使います。

親から子にデータを渡す
list.html
product={bike}

list が持っている1台分の bike オブジェクトを tile の公開プロパティ product に渡します。

子のイベントを受け取る
list.html
ontileclick={handleTileClick}

tile が tileclick を発行したとき、list.js の handleTileClick が実行されます。

子の通知を受ける
list.js
handleTileClick(evt)

evt は tile から届いたイベントです。evt.detail に選択された自転車の Id が入っています。

親向けのイベントを新しく作る
list.js
new CustomEvent('productselected', { detail: evt.detail })

tileclick をそのまま上に流すのではなく、list が productselected という別のイベントを作ります。detail は受け取った Id です。

list から親にイベントを送る
list.js
this.dispatchEvent(event)

作った productselected イベントを selector に通知します。

tile — クリックを知らせる

1台の自転車を表示し、クリックされた Id を list に通知します。

tile.html
<template>
    <div class="container">
        <a onclick={tileClick}>
            <div class="title">{product.fields.Name.value}</div>
            <img class="product-img" src={product.fields.Picture_URL__c.value}></img>
        </a>
    </div>
</template>
何をしている？理解度コードと詳しい説明
親から受け取る公開プロパティ
tile.js
@api product;

list.html の product={bike} がここに入ります。@api があるため親コンポーネントから値を渡せます。

自転車名を表示する
tile.html
{product.fields.Name.value}

受け取った product の Name フィールドの value を画面に表示します。

画像URLを設定する
tile.html
src={product.fields.Picture_URL__c.value}

自転車レコードの画像URLを img 要素の src に使います。

クリックを JavaScript に伝える
tile.html
onclick={tileClick}

ユーザーが a 要素をクリックすると tile.js の tileClick が呼ばれます。

選択した自転車の Id をイベントに入れる
tile.js
new CustomEvent('tileclick', { detail: this.product.fields.Id.value })

detail はイベントに付ける追加データです。ここでは Id という文字列を入れています。

tile から list へ通知する
tile.js
this.dispatchEvent(event)

tileclick を発行します。list.html の ontileclick が受け取ります。

selector — 全体をつなぐ

list の選択通知を受け取り、detail に選択 Id を渡します。

selector.html
<template>
    <div class="wrapper">
        <header class="header">Select a Bike</header>
        <section class="content">
            <div class="columns">
                <main class="main">
                    <c-list onproductselected={handleProductSelected}></c-list>
                </main>
                <aside class="sidebar-second">
                    <c-detail product-id={selectedProductId}></c-detail>
                </aside>
            </div>
        </section>
    </div>
</template>
何をしている？理解度コードと詳しい説明
list のイベントを監視する
selector.html
<c-list onproductselected={handleProductSelected}>

list が productselected を発行すると selector.js の handleProductSelected が動きます。

選択中の Id を保持する
selector.js
selectedProductId;

初期値は undefined です。クリック後は自転車の Id が入ります。

list からの通知を処理する
selector.js
handleProductSelected(evt)

evt.detail には list が送った自転車 Id が入っています。

選択 Id を更新する
selector.js
this.selectedProductId = evt.detail;

イベントで届いた Id を保存します。この変更がテンプレートに反映されます。

detail に Id を渡す
selector.html
<c-detail product-id={selectedProductId}>

HTML の product-id は JavaScript の productId に対応します。親から子へのプロパティ受け渡しです。

detail — 選択した1台を探す

受け取った Id と一致する自転車を探して product に保存します。

detail.js
import { LightningElement, api } from 'lwc';
import { bikes } from 'c/data';

export default class Detail extends LightningElement {
    product;
    _productId = undefined;

    set productId(value) {
        this._productId = value;
        this.product = bikes.find(bike => bike.fields.Id.value === value);
    }

    @api get productId() {
        return this._productId;
    }
}
何をしている？理解度コードと詳しい説明
表示対象の自転車を保持する
detail.js
product;

見つかった自転車オブジェクトを格納するプロパティです。

内部で Id を保持する
detail.js
_productId = undefined;

外部公開の productId と区別するための内部プロパティです。アンダースコアは慣習的な命名です。

親から渡された値を処理する
detail.js
set productId(value)

selector が product-id に新しい値を渡すと setter が呼ばれ、value にその Id が入ります。

受け取った Id を記録する
detail.js
this._productId = value;

getter で返すため、内部プロパティに Id を保存します。

Id が一致する1件を検索する
detail.js
bikes.find(bike => bike.fields.Id.value === value)

配列の先頭から条件に一致する最初の bike を返します。一致しなければ undefined です。

公開プロパティの値を読み出す
detail.js
@api get productId()

getter は _productId を返します。@api によって親から利用できる公開プロパティになります。

覚えておきたいポイント

CustomEvent：イベントを作る。detail：イベントに付ける値。dispatchEvent：イベントを発行する。

on + イベント名：親のHTMLでイベントを受ける。例：ontileclick、onproductselected。

@api：親からアクセスできる公開プロパティ。get：値を読む。set：値を受け取って追加処理する。

注意：detail.html は今回の提供コードに含まれていないため、detail の画面表示部分は解説対象外です。
